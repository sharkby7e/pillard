## Getting started

Requires Ruby (see `Gemfile` for the version) and PostgreSQL.

```sh
bin/setup --skip-server   # installs dependencies, prepares and seeds the database
bin/dev                   # starts the app
```

The app will be running at [http://localhost:3000](http://localhost:3000).

## Running the tests

```sh
bin/rspec
```
